Twin Worlds is an original 2D canvas spot-the-difference game: 5 scenes (Harbor at Dawn, Moonlit Garden, Cozy Library, Desert Oasis, Winter Market) × 8 hand-placed differences (40 total), with rising difficulty, per-scene timers, streak score multipliers, hints, and synthesized WebAudio sounds. All art is drawn procedurally — no external assets, no network. To play it locally, serve the game/ folder (for example `node serve.ts`) and open it in a desktop browser.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
